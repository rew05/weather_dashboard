# てんきダッシュボード 🌤️

現在地の天気を取得して表示する、3日間予報の天気ダッシュボードです。APIキー不要で、静的ファイルをブラウザで開くだけで動作します。

## 特徴

- 📍 **現在地の自動取得** — ブラウザの位置情報 API で現在地を取得し、地名を表示（逆ジオコーディング）
- 🌡️ **きょうの天気** — 気温、最高/最低気温、湿度、風速、降水量、UV指数をまとめたヒーローカード
- 👕 **服装アドバイス** — 気温と天候から、上着・下衣・アウター・雨具の要否を自動提案
- ⏰ **時間別予報** — 選択した日の24時間分の気温・湿度・天気アイコンをスクロール表示
- 📅 **3日間予報** — 日ごとの天気カードをクリックすると、その日の詳細に切り替え
- 💧 **湿度の推移グラフ** — きょう1日の湿度をバーチャートで可視化
- 🔄 **自動更新** — 10分ごとにデータを再取得

## 使用技術

- HTML / CSS / Vanilla JavaScript（フレームワーク不使用）
- [Open-Meteo API](https://open-meteo.com/) — 天気予報データの取得（APIキー不要）
- [Nominatim (OpenStreetMap)](https://nominatim.org/) — 逆ジオコーディングによる地名取得
- Google Fonts（Noto Sans JP / Inter）

weather_dashboard/

## 使い方

1. このリポジトリをクローンまたはダウンロード
2. `index.html` をブラウザで開く
3. 位置情報の利用を許可する

ローカルサーバーが必要な場合は、任意の静的サーバーで配信してください（例）。

```bash
npx serve .
```

## 注意事項

- 天気情報の取得には、ブラウザの位置情報アクセス許可が必要です。
- Open-Meteo / Nominatim はいずれも無料の公開APIを利用しており、利用規約・レート制限に従います。
